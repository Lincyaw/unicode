# 设计系统

本目录是 Aegis Bench 对外站点的设计系统：设计令牌、全局样式和通用组件都在这里，站点各页面只从这里取颜色、尺寸、动效和控件。本目录不依赖任何业务领域，可以整体复制到别的项目中参考或使用。

本文是设计规范，写的是检查表达不了的部分；能机械判断的规则在 `stylelint.config.js` 和 `.oxlintrc.json` 里，由 `npm run check` 执行。

## 目录

| 文件 | 内容 |
|---|---|
| `tokens.css` | 从 Figma 变量导出的令牌：颜色（`Aegis · 颜色`，浅色与深色两套）、圆角与间距（`Aegis · 尺寸`） |
| `base.css` | 站点令牌（字体、版式、尺寸、线宽、文字样式、动效、阴影）、全局重置与全局类 |
| `controls.tsx` | 按钮、提交按钮、复制按钮、图标按钮、分段选择、多选胶囊、输入框、多行输入框、搜索框、下拉选择、范围标签，以及控件用的图标（箭头、折叠、主题、菜单、关闭、外链、文件、全屏、缩放、适合窗口） |
| `navigation.tsx` | 面包屑、标签行、页内分区链接、翻页 |
| `content.tsx` | 标签、带说明的标题、分区标题、事实列表、关键数字、加载提示 |
| `hint.tsx` | 悬浮说明：说明文字和标记的细节不直接写在页面上，悬停或聚焦时才显示 |
| `resizer.tsx`、`storedSize.ts` | 读者自己调宽度的分栏：栏间的拖动条，以及记在浏览器里的宽度 |
| `fullscreen.ts` | 工具型页面的全屏开关 |
| `table.module.css` | 数据表的行与表头 |
| `media.ts` | 断点与减少动态的媒体查询，供脚本使用 |
| `theme.ts` | 切换深色与浅色主题，并记住读者的选择 |

## 令牌

令牌分两层：
- **`tokens.css`** 是 Figma 变量的导出，包括颜色、圆角和间距。修改时先改 Figma 变量，再同步到这个文件。Figma 变量的 Web 代码语法就是对应的 CSS 变量名，例如 `spacing/2` 对应 `var(--space-px)`。
- **`base.css`** 存放 Figma 变量无法表达，或只在代码中有意义的令牌：字体栈、布局尺寸、线宽、文字样式（复合的 `font` 值）、时长与缓动、阴影和渐变。

样式里能写什么值，由 `stylelint.config.js` 检查，每条规则的 message 写明理由。检查之外：
- 正文和页面导语的宽度分别用 `--measure` 和 `--measure-intro`。
- 一个值反复出现、并且有明确含义时，先在 `base.css` 中给它起名，再使用。

### 间距

间距只取 4px 刻度上的值：

| 令牌 | 值 | 令牌 | 值 |
|---|---|---|---|
| `--space-px` | 2px | `--space-6` | 24px |
| `--space-1` | 4px | `--space-8` | 32px |
| `--space-2` | 8px | `--space-10` | 40px |
| `--space-3` | 12px | `--space-12` | 48px |
| `--space-4` | 16px | `--space-64` | 64px |
| `--space-5` | 20px | `--space-96` | 96px |
| | | `--space-120` | 120px |

需要几何对齐时，用令牌计算，例如内缩量取 `calc((var(--space-12) - var(--control-medium)) / 2)`，这样内外圆角保持同心。

### 尺寸

| 用途 | 令牌 |
|---|---|
| 控件高度 | `--control-large` 40px、`--control-medium` 34px、`--control-small` 26px；圆形图标按钮 `--control-icon` 36px |
| 线宽 | `--size-hairline` 1px（分隔线、描边）、`--size-stroke` 1.5px（空心标记）、`--size-border-thick` 2px（强调线、指示条、焦点环） |
| 分隔线 | `--rule-hairline`、`--rule-emphasis`，直接用作 `border` 的值 |
| 圆点 | `--size-dot` 8px、`--size-dot-sm` 6px |
| 布局 | `--content-width` 1200px、`--page-gutter`（120 / 48 / 24px）、`--nav-height`（64 / 56px）、`--anchor-gap` 56px |
| 阅读宽度 | `--measure` 760px、`--measure-intro` 640px |

圆角：标签和徽标用 `--radius-sm`，面板和代码块用 `--radius-md`，卡片和弹层用 `--radius-lg`，下拉面板用 `--radius-2xl`（与内部的胶囊选项同心），控件和圆点用 `--radius-full`。

## 文字

文字样式与 Figma 的 `Site/*` 文字样式一一对应。令牌是 `font` 的复合值，同名的 `.t-*` 类直接应用它：

| 样式 | 规格 | 用途 |
|---|---|---|
| `display` | 600 48/1.16（窄屏 30） | 页面标题 |
| `title` | 600 30/1.22（窄屏 24） | 分区标题、文档的二级标题 |
| `heading` | 500 18/1.4 | 小标题 |
| `lead` | 400 17/1.65 | 页面导语 |
| `body` | 400 15/1.65 | 正文，即 `body` 的默认样式 |
| `label` | 500 14/1.4 | 控件文字、列表项标题 |
| `small` | 400 13/1.6 | 次要文字、表格 |
| `micro` | 400 12/1.5 | 注释、说明、栏目眉题 |
| `mono` | 400 11/1.5 等宽 | 编号、路径、代码标签 |
| `code` | 400 12/1.7 等宽 | 代码块 |
| `bench` | 600 21/1.3 | 评测基准名称 |
| `numeric` | 500 14/1.4，等宽数字 | 分数、计数 |
| `wordmark` | 600 14/1 | 字标 |
| `hero`、`section` | 随窗口缩放 | 首页标题与首页分区标题 |

规则：
- 除等宽文字外只用一个字体栈 `--font-text`：英文字母和数字用 Hanken Grotesk，中文用读者系统里的苹方（PingFang SC），没有苹方的系统依次用微软雅黑、Noto Sans CJK SC。苹方是系统字体，不能作为网页字体加载。
- 等宽字体 JetBrains Mono 只用于编号、路径和代码，不用于数字；数字用 `.t-numeric`，取等宽数字。
- 标题平衡各行的长度，正文避免最后一行只剩一个词；两者都由 `base.css` 全局设置。

## 颜色

颜色按语义使用，不按色值挑选：

| 类别 | 令牌 | 用途 |
|---|---|---|
| 表面 | `--bg-page`、`--bg-panel`、`--bg-muted`、`--bg-inverted`、`--bg-glass`、`--bg-glass-strong`、`--bg-glass-thin` | 页面；凸起的面板和代码；悬停与轨道；实心按钮和提示气泡；浮在内容上的导航与弹层；滚动后浮起的导航药丸，透出下面的页面 |
| 文字 | `--text-main`、`--text-muted`、`--text-faint`、`--text-on-inverted` | 主要文字；次要文字；元信息和占位；反色表面上的文字 |
| 边线 | `--border-hairline`、`--border-emphasis`、`--border-glass` | 分隔线；控件描边；玻璃表面的边 |
| 循环两半 | `--brand-dev`、`--brand-ops` | 研发一半为蓝，运维一半为琥珀；容器写 `data-half="dev"` 或 `"ops"`，内部统一读取 `--half-color` 和 `--half-color-soft` |
| 状态 | `--accent-success`、`--accent-warning`、`--ink-warn` 及对应的 `*-soft` 底色 | 只表示真实的状态：通过、失败或告警、需要留意 |
| 焦点 | `--accent-brand` | 焦点环 |
| 数据 | `--data-*`、`--series-*`、`--replay-*` | 图表系列、模型厂商位、轨迹步骤的类别 |

循环两半的颜色不用来表示状态，状态色也不用于装饰。

分类色 `--data-cat-1` 到 `--data-cat-7` 按固定顺序使用，深浅两套分别通过 dataviz 色板检查（亮度带、色彩度下限、相邻两色在色觉障碍与正常视觉下的区分度、对页面和面板的 3:1 对比）。顺序本身是检查的一部分：相邻的两个槽位明暗交替，所以不要跳着取色。厂商位与轨迹步骤都引用这些槽位，不另设颜色；「思考」这类不需要区分的步骤用中性的 `--text-faint`。

## 控件

- **形状**：所有可点击的控件都是胶囊形，以便和矩形的卡片、面板区分开。尺寸只有大（40）、中（34）、小（26）三档；图标按钮是 36 的圆形，紧凑的工具条里用 26 的小号。
- **安静控件**：一排控件里只让一个带描边，其余用 `quiet`：保留胶囊的形状和尺寸，去掉描边和流光边，文字弱化，悬停时文字变深、出现底色。页头就是这样：对外站点只留「联系我们」一个胶囊，中台只留头像；语言、主题、「登录」和「对外站点」都是安静控件。
  - 筛选栏也是一排：搜索框留描边，下拉都用安静的；没有搜索框时，留第一个下拉。安静的下拉保留下拉箭头，宽度随当前选项，打开时和悬停时一样出现底色。
  - 一排按钮留主操作的描边，其余安静，描边的排在最后，例如运行页的「查看任务」「回放」「与同题运行对照」；表格里每行同理，只留这一行的主控件。
- **按钮**：实心按钮推动读者往下一步走，带箭头，悬停时发光，一个区域里最多放一个；其余操作都用描边按钮。
- **∞ 流光边**：胶囊控件带 `.loop-edge` 类。悬停时，边缘的研发蓝到运维琥珀渐变绕边流动；选中时渐变静止显示；按下时控件轻微收缩。分段选择的流光边画在轨道上，轨道里的选项不带这个类，免得选项的边贴着轨道的边。
- **文字链接**：`textLink` 的下划线以同一渐变从左侧展开，箭头随之右移。
- **下拉选择**：基于 Radix Select。面板是玻璃材质，选项是胶囊；面板圆角与选项保持同心；当前选项带对勾。

## 动效

- **时长**：`--duration-fast`（0.15s）用于颜色和选项高亮；`--duration-base`（0.25s）用于大多数状态变化；`--duration-slow`（0.4s）用于形状变化和指示条移动；`--duration-sweep`（2.4s）是流光绕一圈的时间。
- **缓动**：`--ease-out`，减速、不回弹。
- **出现方式**：弹层、菜单和悬浮说明从触发方向淡入，带 4px 位移，不放大。复制成功时画出对勾。标签行的指示条滑到当前项，分段选择的底色滑到选中项。
- **减少动态**：用户要求减少动态时，全局关闭过渡和动画；首页的场景停在最后一帧。

## 焦点与无障碍

- 所有可交互元素在 `:focus-visible` 时显示 2px 的 `--accent-brand` 焦点环。下拉选项例外：它的高亮就是焦点指示。
- 导航区域带可读的名称。
- 状态不只靠颜色表达，同时配有文字或形状，例如“执行失败”画成空心圈。

## 主题与响应式

- **主题**：主题由 `<html data-theme="light|dark">` 决定。`index.html` 在首帧绘制前写入用户上次的选择，没有选择时跟随系统；`tokens.css` 为两种主题各定义一套颜色。脚本绘制的部分（例如首页的画布）用 `getComputedStyle` 读取令牌，并在 `data-theme` 变化时重新读取。
- **断点**：主断点是 760px，对应 `media.ts` 中的 `NARROW_QUERY`；宽布局另有 1100px 和 1280px 两档。

## 组件

| 组件 | 说明 |
|---|---|
| `ButtonLink`、`Button` | 大号胶囊按钮，有实心（`solid`）、描边（`line`）和安静（`quiet`）三种 |
| `SubmitButton` | 提交所在表单的按钮，实心或线框与 `Button` 相同；提交进行中变淡且不可点 |
| `TextField` | 带标签的胶囊输入框，标签在上；可给出格式，浏览器在格式不符时拦下表单，提示写在框下 |
| `TextArea` | 带标签的多行输入框；它是输入区而不是控件，所以用卡片的圆角 |
| `ToggleChip` | 可单独开关的胶囊，用于多选；打开时带对勾 |
| `CopyButton` | 复制一段文字，成功后在旁边画出对勾 |
| `IconButton` | 圆形图标控件，执行操作（`onClick`）、打开站内页面（`to`）或在新标签页打开站外地址（`href`）。悬停时图标旋转半圈，箭头图标（`ArrowIcon`、`LinkArrowIcon`）则朝所指方向轻移，有正反之分的图标（`FileIcon`、`FullscreenIcon`、`ZoomIcon`、`FitIcon`）不动；不可用时变淡、不动；`variant="quiet"` 时不带描边；`size="small"` 时与小号胶囊同高（26），用在紧凑的行里 |
| `MoreButton` | 在列表末尾加载下一页，文字说明已显示多少，加载时变淡且不可点 |
| `SegmentedControl` | 一条轨道内互斥的几个选项；选中项的底色从原来的选项滑过去，悬停的选项文字变亮。`captions` 给连续的几个选项加一行标题，例如评测基准所属的环节：标题在轨道上方，各自盖住自己的选项，标题比选项宽时选项随之加宽 |
| `SearchField` | 胶囊形搜索框 |
| `Select` | 胶囊触发器和玻璃面板组成的下拉选择；`variant="quiet"` 时不带描边，保留下拉箭头 |
| `ScopeChip` | 页面限定的范围，例如从模型页带来的模型：名称加 × 的小胶囊，`to` 是去掉这一范围后的地址，点击即回到全部，并替换当前的历史记录；悬浮说明和读屏名称都取 `ui.clearScope`。排在一行末尾时靠到行尾，排在其他控件之前时留在它们旁边 |
| `Breadcrumbs` | 当前位置 |
| `TabRow` | 标签行，渐变指示条滑到当前项 |
| `SectionLinks` | 页内分区链接，标出正在阅读的分区 |
| `Pager` | 前后翻页的两个箭头按钮和当前范围，到头的一侧不可点 |
| `Tag` | 不可点击的标签，例如版本号或状态，可设为虚线框 |
| `HintedHeading` | 指定级别和文字样式的标题，旁边的 ⓘ 收着解释这一部分的话，例如计数口径；没有说明时只是标题。中台页头、分区标题和运行详情的小标题都由它画 |
| `SectionHeading` | 对外站点的分区标题，说明收在标题旁的 ⓘ 里 |
| `FactList` | 一组“名称—值”，有纵排、两栏和行内三种排法 |
| `StatTile`、`StatTiles` | 页面的关键数字：名称（计数口径收在名称旁的 ⓘ 里）、数字和一行相关的数字，例如未计入的次数；一组自动换行 |
| `Loading` | 加载中的提示 |
| `Hint` | 基于 Radix Tooltip。把任意可聚焦的元素变成触发器，悬停或聚焦时在旁边弹出玻璃卡片，显示说明或标记的细节；整站由 `HintProvider` 共享延迟。卡片的玻璃样式和出现方式是 `hint.module.css` 的 `.popover`，页面里的其他弹层也用它，自己定层级、尺寸和内边距 |
| `InfoHint` | 一个小的圆形 ⓘ 按钮，悬停时说明旁边的内容；页面上的解释性小字一律收进它 |
| `ResizeHandle`、`useStoredSize` | 两栏之间的拖动条：拖动或用左右方向键调整一侧栏的宽度，双击恢复默认；悬停、拖动和聚焦时显出一条线。宽度是读者的偏好，由 `useStoredSize` 记在浏览器里，不写进地址，并限制在上下限之间 |
| `useFullscreen` | 工具型页面的全屏：打开后请求浏览器全屏（看不到地址栏和标签栏），不论浏览器是否同意，页面都盖住站点的顶栏、铺满窗口，页面自己决定收起哪些部分。按 Esc、用浏览器自己的方式退出全屏或离开页面都会关闭；全屏不写进地址 |
| `table.module.css` | 数据表的行，列宽由使用方通过 `--columns` 设置；解释某一列的话收进列名旁的 ⓘ，列名单元格用 `.hinted`。各列合计宽于可用宽度时，表格在自己的框内横向滚动，页面不随之滚动。可点的行（`.link`）不监听点击，由行里的主链接（`.primary`）铺满整行，键盘通过主链接进入；行里其他的链接和按钮浮在上面，各自打开自己的地址 |

全局类：`.t-*`（文字样式）、`.c-*`（文字颜色）、`.page`（页面内容宽度与边距）、`.visually-hidden`（只给读屏器的文字）、`.loop-edge`（∞ 流光边）。

## 新增组件

1. 先查上面的组件表，能用已有组件或给已有组件加一个参数解决的，就不新建。
2. 新组件按概念放进已有文件（控件、导航、内容）；属于新概念时，新建一个以概念命名的 `.tsx` 及同名的 `.module.css`。
3. 在深色和浅色两种主题下，分别按 1440 和 390 两种宽度检查，然后运行 `npm run check`。
4. 新的视觉样式同时画进 Figma 文件 `Aegis Bench`；新令牌先在 Figma 变量中建立，再同步到 `tokens.css`。

## 在别的项目中使用

1. 复制本目录。在入口文件里先引入 `base.css`，它会接着引入 `tokens.css`。
2. 在 `index.html` 中引入 Hanken Grotesk 和 JetBrains Mono 两种网页字体，并加入在首帧前设置 `data-theme` 的脚本（见本仓库的 `index.html`）。
3. 复制 `stylelint.config.js`，把 `TOKEN_FILES` 指向本目录的两个令牌文件。
4. 本目录对站点有以下几处依赖，都要替换成使用方自己的实现：
   - `ButtonLink`、`ScopeChip` 和面包屑通过 `../i18n/LocaleRouting` 的 `LocaleLink` 保持当前语言；
   - 面包屑通过 `../i18n/trail` 的 `useReturnPath` 回到读者来时的地址，需要在路由的根上提供 `TrailContext`；
   - 复制按钮、范围标签和面包屑读取 `ui.*` 文案（`ui.copied`、`ui.clearScope`、`ui.breadcrumbs` 等）；
   - `theme.ts` 从环境变量 `VITE_THEME_STORAGE_KEY` 读取记住主题的键，与 `index.html` 的脚本一致。
